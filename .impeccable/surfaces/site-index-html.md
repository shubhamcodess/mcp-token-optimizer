# Surface brief: landing page

Scope: single-page marketing surface for mcp-token-optimizer (`site/`, Vite + React, static, GitHub Pages). Visitor mode: Persuade. Primary action: install. First proof: the saving, live, inside a realistic coding-agent screen.

Audience and constraints: sceptical developers running AI agents with MCP servers; facts only from PRODUCT.md (no invented claims; npm is "coming in v3"); WCAG AA in both themes; reduced motion gets static final states; phone width.

Sections: hero with agent-app mock, agent logo strip, how it works (animated pipeline), features (framed grid, one line each), benchmarks (dot-matrix figures), install guide, test it (terminal with real smoke output), feedback (prefilled GitHub issue), footer.

History: a first flat, windowless, typographic build was rejected by the user as text-heavy and lacking taste. This brief replaces it.

## Direction contract

THESIS: The page is a developer's night console where you watch mto work. A realistic agent app plays the real list_issues call: 37,355 tokens arrive, noise is struck out, 13,244 reach the model. It refuses the prose-led marketing page: every section shows a working artifact (app, pipeline, figure, terminal) with a one-line caption.

OWN-WORLD: Dark default on deep indigo (#0f0d1c, never black), light theme on pale lilac (#f5f3fc); hairline-framed content column with side rules; a canvas dot-matrix field behind everything whose dots are tokens: a slow sweep dims them (pruned) and the cursor lifts them. Lavender is the brand, coral marks noise, mint marks what is saved. Mona Sans for headings, JetBrains Mono for everything machine. App mock is always dark, with real window chrome.

STORY: The visitor sees the agent call a tool, sees the bloated response cut, believes the number because the output is the real mto output and every figure names its command, then copies the install line.

FIRST VIEWPORT: Short headline and one-line subline left, install command pill with copy plus Download and GitHub actions beneath; the agent app mock spans the content column below, its top third visible above the fold, playing the cut on a loop while visible. Dot field and a soft lavender glow sit behind.

FORM: Dev-tool console in the line of Cursor's app hero, OpenCode's framed mono column and dot figures, Kiro's terminal-on-colour (pinned by the user; no seed roll run). seed: none (unavailable)

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
